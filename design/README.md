# design — デザインキャンバスの写し

画面デザインの正本は Claude のアーティファクト（キャンバス「calendar-alarm デザイン」）。
このディレクトリは、実装する人と AI がリポジトリの中で読むための写し。

- 正本: https://claude.ai/artifact/VqUeceTJYaL9Z3U2JyLnNm （非公開。持ち主のアカウントで開く）
- 写した版: `1794404197-426d`
- 写した日時: 2026-11-12 02:43 UTC（`date` の値）
- 写しと正本が違う時は、正本が正しい。写しを直接は編集しない。正本が変わったら写し直す

## 置いた物

| パス | 中身 |
|---|---|
| `project/canvas.json` | ボードの一覧・題・並び・大きさ（キャンバスの目次） |
| `project/*.dc.html`、`project/d68/*.dc.html` | ボード1枚 = 1ファイル。正本の `project/` と同じパス・同じ中身 |
| `asset/41384cd4ff5e02c5cffc251dcfb23a2b.css` | 全ボード共通のスタイル（Night UI 第2版）。色・角丸・書体・部品の形の値はここ |

正本のうち、キャンバスの編集画面そのもの（`artifact-type/` と `index.html`）は写していない。

## 読み方

- ボードの HTML は正本のままで、手を入れていない。このリポジトリの中だけでは画面として表示できない
  （`./support.js` はキャンバスの実行部品、`/_blob/41384cd4…` は正本側の置き場を指す）。
  見た目を確かめる時は正本を開く
- `<link href="/_blob/41384cd4ff5e02c5cffc251dcfb23a2b">` は `asset/41384cd4ff5e02c5cffc251dcfb23a2b.css` のこと
- 色は CSS の変数。`.r`（ダーク）と `.r[data-theme=light]`（ライト）の2組が `asset/` の CSS の先頭にある
- 各ボードは「列」（`<div class="col">`）の並び。列の見出し（`.cap`）に付いた `#番号` の札は、
  今の実装と違う所を受け持つ PBI。札の無い列は、今の実装のとおりに描いた物か「未実装の案」
- 画面の中の予定名・アカウント（`work@example.com` など）は見本の値
